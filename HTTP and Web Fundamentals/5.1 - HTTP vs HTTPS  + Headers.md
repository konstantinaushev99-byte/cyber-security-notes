# HTTP + Headers
## HTTP - это протокол обмена сообщениями между клиентом и сервером

### Базовая модель
1. Когда мы открываем, например: https://example.com
2. Происходит примерно следующее:
   ```bash
   Browser (Client)
         |
         |  HTTP Request 
         ▼
     web Server
         |
         |  HTTP Response
         ▼
     Browser (Client)
   ```
Client - обычно браузер, который отправляет запрос
Server - компьютер/программа, которая принимает запрос и возвращвет результат
3. Например браузер может отправить:
   ```bash
   GET / HTTP/1.1
   Host: example.com
   ```
4. И отвечает примерно это:
   ```bash
   HTTP/1.1 200 OK
   Content-Type: text/html

   <html>
   ...
   </html>
   ```
- Requsest - клиент просит что-то у сервера
- Responce - сервер отвечает клиенту    

# HTTP vs HTTPS 
## HTTP - данные передаются в открытом виде (plain text), любой посредник в сети (провайдер, Wi-fi точка, атакующий в той же сети) может прочитать содержимое запроса/ответа.
## HTTPS - тот же протокол HTTP, но обернутый в шифрование TLS/SSL. Данные передаются зашифрованными, посредник видит только факт соединения (домен через SNI), но не содержимое.

Порты по умолчанию - HTTP - 80, HTTPS - 443

# Headers
Пример 1:
```bash
GET /admin HTTP/1.1
Host: test.com
```
Headers в данном примере - Host: test.com

Пример 2:
```bash
GET /admin HTTP/1.1
Host: test.com
User-Agent: Mozilla/5.0
Cookie: session=abc123
```
- User-Agent - какой браузер/клиент отправил запрос
- Cookie - сюда логично подводит следующая тема моего списка (Cookie/Sessions)
