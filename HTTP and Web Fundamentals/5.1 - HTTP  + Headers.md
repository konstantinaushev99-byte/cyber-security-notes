# HTTP + Headers
## HTTP - это протокол обмена сообщениями между клиентом и сервером

### Базовая модель
1. Когда мы открываем, например: https://example.com
2. Происходит примерно следующее:
   ```bash
   Browser (Client)
         |
         |  HTTP Request 
         ▼
     web Server
         |
         |  HTTP Response
         ▼
     Browser (Client)
   ```
Client - обычно браузер, который отправляет запрос
Server - компьютер/программа, которая принимает запрос и возвращвет результат
3. Например браузер может отправить:
   ```bash
   GET / HTTP/1.1
   Host: example.com
   ```
4. И отвечает примерно это:
   ```bash
   HTTP/1.1 200 OK
   Content-Type: text/html

   <html>
   ...
   </html>
   ```
- Requsest - клиент просит что-то у сервера
- Responce - сервер отвечает клиенту    

# Headers
Например:
```bash
GET /admin HTTP/1.1
Host: test.com
```
Headers в данном примере - Host: test.com
