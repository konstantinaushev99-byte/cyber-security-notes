# What is access control(контроль доступа)? - это применение ограничений к тому, кто или что имеет право выполнять действие или получать доступ к ресурсам 
Контроль доступа зависит от аутентификации и управления сессиями:
- Аутентификация подтверждает, что пользователь действительно является тем, за кого себя выдает
- Управление сессиями позволяет определить, какие последующие HTTP-запросы отправляет тот же пользователь
- Контроль доступа определяет, разрешено ли пользователю выполнять действие, которое он пытается совершить

# Vertical access controls(Вертикальные элементы управления доступом) - это механизмы, ограничивающие доступ к конфиденциальныйм функциям для определенных типов пользователей
При вертикальном контроле доступа разные типы пользователей имеют доступ к разным функциям приложения
Может представлять собой более детальную реализацию моделей безопасности, преднозначеннх для обеспечения соблюдения бизнес-политик, таких как разделение обязанностей и принцип минимальных привилегий

# Horizontal access controls(Горизонтальные элементы управления доступом) - это механизмы, ограничивающие доступ к ресурсам для конкретных пользователей
При горизонтальном управлении доступом разные пользователи имеют доступ к ограниченному набору ресурсов одного типа

# Context-dependent access controls(Контекстно-зависимые элементы управления доступом) - ограничивают доступ к функциям и ресурсам в зависимости от состояния приложения или взаимодействия пользователя с ним
Контекстно-зависимые средства контроля доступа предотвращают выполнение пользователем действий в неправильном порядке

# Examples of broken access controls(Примеры неработающих систем контроля доступа) - Уязвимости, связанные с нарушением контроля доступа, возникают, когда пользователь может получить доступ к ресурсам или выполнять действия, которые ему не положены
