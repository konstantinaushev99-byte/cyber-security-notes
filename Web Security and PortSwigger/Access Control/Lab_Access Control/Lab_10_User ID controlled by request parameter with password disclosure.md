# User ID controlled by request parameter with password disclosure
## Цель: В этой лабораторной работе используется страница учетной записи пользователя, на которой отображается текущий пароль пользователя, предварительно заполненный в поле ввода с маской.
Для решения лабораторной работы получите пароль администратора, а затем используйте его для удаления пользователя carlos


### Решения:
1. Для начало входим в свой аккаунт
2. Дальше меняем свой id на id carlos, мы зашли на его акк и увидим пароль, но сменить его не сможем
3. Что мы тогда делаем , отправляем запрос в Repeater и нажмаем send , далее ищем пароль внутри кода, пароль узнали
4. Если таким методом мы узнали пароль Carlos , то сможешь сделать и с админом, меняем id либо на admin, либо на administrator
5. И повторяем теже действия что и с Carlos
6. После чего заходим в админ панель и удаляем пользователя Carlos
