# Unprotected admin functionality
## Цель: Удалить пользователя Carlos

### Пути решения:
1. Проверив все URL которые подходят под слова admin,administrator и т.д ни одна из ссылок не сработала
2. Тогда я зашел по URL - ```https://0a06008b03ed93e782c9a63e00e10053.web-security-academy.net/robots.txt```
3. Там оказалась ссылка на панель админа - ```/administrator-panel```
4. Потставляем значения в ссылку и удаляем пользователя Carlos
