# User role controlled by request parameter
## Цель: В этой лаборатории есть панель администратора /admin, которая идентифицирует администраторов с помощью поддельного cookie-файла, нужно войти и удалить пользователя Carlos, также у нас есть свои данные 

### Пути решения:
1. Первым делал сразу попробывал войти с помощью ссылки /admin, но не удалось - ```Admin interface only available if logged in as an administrator```
2. Тогда я отправил это запрос в Repeater, поигрался с куки и токенами, но это тоже не сработало
3. Я сделал еще один такой запрос и увидел что на Admin стоит парметр false, и тогда я понялд что можено перехватить запрос и сменить параметр
4. Для начало включаю ```Intercept off``` , после этого делаю запрос на вызов панели админа, захожу в запрос и меняю ```Admin=false```, на ```Admin=true``` и нажимаю Forward чтобы отправить запрос дальше
5. После того как мы вошли в панель, нажимаю на Delete возле Carlos, снова перехватываем и пишем true
