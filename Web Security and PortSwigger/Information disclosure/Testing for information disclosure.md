# Testing for information disclosure(Проверка на предмет раскрытия информации)

## Как проверить наличие уязвимостей, приводящих к раскрытию информации
Утечка конфиденциальных данных может произойти в самых разных местах, поэтому важно не упустить ничего, что может оказаться полезным в дальнейшем. Часто конфиденциальные данные обнаруживаются во время тестирования чего-то другого. Ключевой навык — умение распознавать интересную информацию, где бы и когда бы она ни встречалась

Некоторые примеры высокоуровневых методов и инструментов:
1. Fuzzing
2. Using Burp Scanner
3. Using Burp's engagement tools
4. Enginneering informative responses

### 1. Fuzzing
Если вы обнаружите интересные параметры, попробуйте отправить неожиданные типы данных и специально созданные тестовые строки, чтобы посмотреть, какой эффект это даст
Например, это может быть небольшая разница во времени обработки запроса

Часть этого процесса можно автоматизировать с помощью Burp Intruder:
1. Добавляйте позиции полезной нагрузки к параметрам и используйте предварительно созданные списки слов для фаззинга
2. Легко выявляйте различия в ответах, сравнивая коды состояния HTTP, время ответа, длину и так далее
3. Используйте правила сопоставления grep для быстрого выявления вхождений ключевых слов, таких как error, invalid, SELECT, SQL

### 2. Burp Scanner
Пользователи Burp Suite Professional могут воспользоваться Burp Scanner
Он предоставляет функции сканирования в режиме реального времени для аудита элементов во время просмотра веб-страниц

Так же можно запланировать автоматическое сканирование и аудит сайта от вашего имени
Burp Scanner предупредит вас, если обнаружит в ответе конфиденциальную информацию, такую ​​как закрытые ключи, адреса электронной почты и номера кредитных карт

### 3. Using Burp's engagement tools
Burp предоставляет несколько инструментов для взаимодействия с пользователями, которые помогут вам легче находить интересную информацию на целевом веб-сайте
Просто щелкните правой кнопкой мыши по любому HTTP-сообщению, записи Burp Proxy или элементу на карте сайта и выберите «Инструменты взаимодействия»

В данном контексте особенно полезны следующие инструменты:
1. Search
2. Find comments
3. Discover content

### 4. Engineering informative responses
Подробные сообщения об ошибках иногда могут раскрыть интересную информацию в процессе обычного тестирования, но изучив как меняются сообщения об ошибках в зависимости от входных данных , в некоторых случаях сможем манипулировать сайтом, чтобы извлеть произвольные данные 

Один из распространенных примеров — заставить логику приложения попытаться выполнить недопустимое действие с определенным элементом данных
Например, отправка недопустимого значения параметра может привести к трассировке стека или отладочному ответу, содержащему важные подробности. Иногда можно настроить сообщения об ошибках так, чтобы они раскрывали значение нужных данных в ответе
