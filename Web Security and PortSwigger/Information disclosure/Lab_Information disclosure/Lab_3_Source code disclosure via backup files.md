# Source code disclosure via backup files
## Цель: Найти закодированый исходный код и доставть пароль от базы данных

### Пути решения: 
1. Так как в обычном исходном коде я ничего не нашел
2. Я ввел в поиск /robots.txt, там была ссылка на путь похожего на закодированый код - /backup
3. После перехода в backup, увидел ссылку на код, внутри которого нашел пароль - 1sgfc16hekzehkdwegxg513cwv38datq

Ссылка: https://portswigger.net/web-security/information-disclosure/exploiting/lab-infoleak-via-backup-files
