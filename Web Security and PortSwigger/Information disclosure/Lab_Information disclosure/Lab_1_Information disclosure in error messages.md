# Information disclosure in error messages
## Цель: Узнать версию фреймворка и отправить ее номер

### Пути решения:
1. В данной лабе, в аккаунт входить нам не надо, значит мы будем искать ошибки в коде, структуре и т.д
2. Первое что я сделал просмотрел исходный код, нету ли каких-либо комметарий которые укажут на фреймворк
3. Далее я просмотрел код страницы товара
4. И решил вызвать ошибку с помощью нецелочисленных типов данных написав вместо - /product?productId=1, написать /product?productId="ex"
5. Дало ошибку и внизу написан фреймворк - Apache Struts 2 2.3.31
