# Vulnerabilities in password-based authentication

## Brute-force attacks(Атака методом перебора) - это когда злоумышленник использует систему проб и ошибок, чтобы угадать действительные учетные данные пользователя.
Брутфорсинг - это не всегда просто случайное угадывание имен пользователей и паролей. Используя также базовую логику или общедоступные знания, злоумышленники могут точно настроить атаки методом брутфорса для получения гораздо более обоснованных предположений.

# Brute-forcing usernames(Логины пользователей с помощью брутфорсинга) - имена пользователей особенно легко угадать, если они соответствуют узнаваемому шаблону, такому как адрес электронной почты.

# Brute-forcing passwords(Взлом паролей методом перебора) - Пароли также можно взломать методом перебора, причем сложность взлома зависит от степени надежности пароля. Многие веб-сайты применяют те или иные правила создания паролей, которые обязывают пользователей создавать пароли с высокой энтропией, которые, по крайней мере теоретически, сложнее взломать с помощью одного лишь метода перебора.
Однако, хотя пароли с высокой энтропией сложно взломать с помощью одних только компьютеров, мы можем использовать базовые знания о поведении людей, чтобы воспользоваться уязвимостями, которые пользователи невольно вносят в эту систему.

# Username enumeration(перебор имен пользователей) - это ситуация, когда злоумышленник отслеживает изменения в поведении веб-сайта, чтобы определить, является ли данное имя пользователя действительным. 
Перебор имен пользователей обычно происходит либо на странице входа в систему, либо в регистрационных формах, когда вы вводите имя пользователя, которое уже занято.
При попытке перебора всех возможных вариантов на странице входа в систему следует обращать особое внимание на любые различия в:
- Коды статуса
- Сообщения об ошибках
- Время отклика

# Flawed brute-force protection(Несовершенная защита от атак методом перебора) - защита от атак методом перебора заключается в том, чтобы максимально затруднить автоматизацию этого процесса и снизить скорость, с которой злоумышленник может предпринимать попытки входа. 
Двумя наиболее распространёнными способами предотвращения атак методом перебора являются:
1. Блокировка учетной записи, к которой удаленный пользователь пытается получить доступ, в случае слишком большого количества неудачных попыток входа
2. Блокировка IP-адреса удаленного пользователя, если он совершает слишком много попыток входа подряд
 некоторых реализациях счетчик количества неудачных попыток сбрасывается, если владелец IP-адреса успешно войдет в систему. Это означает, что злоумышленнику достаточно просто входить в свою учетную запись каждые несколько попыток, чтобы этот лимит никогда не был достигнут.

# Account locking(Блокировка учетной записи)
Для обхода такого рода защиты можно использовать следующий метод:
1. Составьте список возможных имен пользователей, которые, вероятно, являются действительными.
2. Составьте очень короткий список паролей, которые, по вашему мнению, может использовать хотя бы один пользователь.
Важно!!! -  чтобы количество выбранных паролей не превышало допустимое количество попыток входа.
С помощью такого инструмента, как Burp Intruder, попробуйте каждый из выбранных паролей с каждым из возможных имен пользователей. Таким образом, вы сможете попытаться взломать каждую учетную запись методом перебора, не вызвав блокировку учетной записи
