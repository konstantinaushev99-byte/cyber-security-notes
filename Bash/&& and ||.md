# && and ||
Что это - это способ объединить несколько условий в одном if, не открывая отдельные [ ] блоки и не вкладывая if друг в друга

---

# && - логическое "И" (оба условия должны быть истинны)
```bash
if [ $port -gt 0 ] && [ $port -lt 1024 ]; then
    echo "Это привилегированный порт"
fi

Сработает, только если и первое условие истинно, и второе. Если хотя бы одно ложно — весь if не выполнится
```

---

# || - логическое "ИЛИ" (достаточно, чтобы хотя бы одно было истинно)
```bash
if [ $port -eq 80 ] || [ $port -eq 443 ]; then
    echo "Это веб-порт"
fi

Сработает, если порт равен либо 80, либо 443 — достаточно совпадения с одним из вариантов
```

# Разница между &&/|| внутри [] и снаружи
Вариант 1 — между двумя отдельными [ ] блоками:
```bash
if [ $port -eq 80 ] || [ $port -eq 443 ]; then
```
Вариант 2 — внутри одних [ ], через -a/-o
```bash
if [ $port -eq 80 -o $port -eq 443 ]; then
```
-a = "и" (and), -o = "или" (or) — работают так же, но считаются устаревшими, современные скрипты обычно используют именно &&/|| между отдельными скобками, как в Варианте 1
