# elif
Что это - решает конкретную проблему — что делать, когда вариантов больше двух, а не просто "да/нет"

---

# Проблему которую решает elif
С обычным if/else у вас только два пути:
```bash
if [ условие ]; then
    вариант А
else
    вариант Б
fi
```
А что, если нужно проверить несколько разных условий по очереди? Раньше пришлось бы вкладывать if внутрь else (z уже так делал в примере с -z):
```bash
if [ условие1 ]; then
    вариант А
else
    if [ условие2 ]; then
        вариант Б
    else
        вариант В
    fi
fi
```
### Решение — elif (сокращение от "else if")
```bash
if [ условие1 ]; then
    вариант А
elif [ условие2 ]; then
    вариант Б
else
    вариант В
fi
```
Тут нет вложенности — все условия идут ровно, одно за другим, и код гораздо легче читать. fi пишется только один раз в самом конце, сколько бы elif ни было.
