# While
Что это - повторяет действие пока условие истинно, и заранее неизвестно, сколько раз это повторится

### Базовый синтаксис
```bash
while [ условие ]; do
    команда
done
```

---

# Пример 1 ( счетчик )
```bash
count=1

while [ $count -le 5 ]; do 
    echo "Попытка номера $count"
    count=$((count + 1 ))
done

Если забыть строку count=$((count + 1)), условие $count -le 5 будет вечно истинным, и в результате будет бесконечный цикл
```

# Пример 2 (ждать, пока хост будет доступен)
```bash
ip=$1

while ! ping -c1 "$1" > /dev/null; do  # "!" перед ping означает "НЕ", тоесть пока хост недоступен - продолжать ждать
    echo "Хост $ip еще недоступен, жду..."
    sleep 2 # пауза на 2 секунды
done

echo "Хост $ip теперь доступен"
```

# Пример 3 ( с count )
```bash
ip=$1
count=0

while ! ping -c1 "$1" > /dev/null; do
    count=$(( count + 1 ))
    echo "Хост $ip еще недоступен, попытка $count"
    sleep 1 
done

echo "Хост $ip теперь доступен! Потребовалось попыток: $count"
```
