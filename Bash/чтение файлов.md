# Чтение файлов

---

# Способ 1 - то, что я уже использовал: for + cat
```bash
for ip in $(cat "$file")
do
    echo "$ip"
done
```
Если в файле окажется строка вроде "192.168.3.109 - мой хост" (с пробелом внутри), for разобьёт её на два отдельных элемента: 192.168.3.109 и -, и мой, и хост — каждое слово отдельно, что не то, что нужно

# Способ 2 - через while read (построчно, без разбивки по пробелам)
```bash
while read -r line
do
    echo "$line"
done < "$file"
```
### Разберём по частям:
1. read -r line — читает одну строку целиком (включая пробелы внутри неё) и кладёт в переменную line
2. -r - защищает от превращения обратных слэшей в спецсимволы
3. < "$file" -  это перенаправление на вход, оно "скармливает" содержимое файла команде while read, построчно, одна строка на одну итерацию цикла

# Способо 3
```bash
check_host() {
    ip=$1
    ping -c1 "$ip" > /dev/null
    if [ $? -eq 0 ]; then
        echo "$ip - доступен"
        return 0
    else  
        echo "Обнаружен недоступный хост: $ip, прекращаю проверку"
        return 1
    fi
        
}

file=$1

while read -r ip
do 
    ip=$(echo "$ip" | cut -d'#' -f1 | xargs) # 

    if [ "$ip" = "192.168.3.109" ]; then
        echo "$ip это моя виртуалка ее не трогать!!!"
        continue
    elif [ "$ip" = "192.168.3.116" ]; then
        echo "$ip это тоже моя виртуалка, не трогать"
        continue
    elif [ "$ip" = "192.168.3.1" ]; then
        echo "$ip это роутер, не трогать"
        continue
    fi

    check_host "$ip"
    if [ $? -ne 0 ]; then
        break
    fi
done < "$file"
```
