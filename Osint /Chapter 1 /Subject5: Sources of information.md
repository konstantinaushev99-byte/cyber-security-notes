# Sources of information(источники информации)

# Категория 1 - Регистрационные и инфраструктурные данные
- WHOIS/RDAP - кто владеет доменом, когда зарегистрирован, контактные данные (если не скрыты приватностью регистратора)
- DNS-записи - A,AAAA,MX,NS,TXT и другие - техническая карта того, как устроена инфраструктура домена
- Сертификаты(crt.sh, Certificate Transparency logs) - каждый раз, когда организация выпускает SSl/TLS-сертификат, это публично логируется.
- Shodan/Censys - поисковыики по устройствам, подключеные к интернету.Кто-ко уже просканировал весь интернет заранее, вы просто читаете результаты

# Категория 2 - Поисковые системы
- Google/Bing dorking - продвинутые операторы посика (site:,filetype:,intitle:,inurl:)
- Wayback MAchine(web.archive.org) - архив исторических версий веб-страниц
- Специализированные поисковики - напрмер, поиск конкретно по коду(Github serch, grep.app) - полезно, если ищете утечки паролей/ключей API в публичных
репозиториях

# Категория 3 - Социальные сети и человеческие фактор
- Linkedln - структура компании, должность, технологии,связи между сотрудниками
- Twitter/X,Instagram,Facebook - лчная информация сотрудников, иногда неосторожно раскрыввающая рабочии детали(фото робочего стола с открытым терминалом, геометки на территории офиса)
- GitHub/Gitlab - код разработчиков компании часто раскрываетиспользуемые технологие, иного - случайно закоммиченые пароли/ключи,внутренние комметарии
- Форум,Reddit,Stak Overflow - сотрудники, ищущие помощь с конктретной технической проблемой, иногда невольно раскрывает детали внутренней инфраструктуры

# Категория 4 - Технический отпечаток
- HTTP-заголовки сайта - серверов, иногда весрия ПО
- Просмотр исходного кода страницы - комментарии разработчиков, пути к файлам используемые JS-библиотеки
- Wappaalyzer и подобные инструменты - автоматическое определение технологии сайта

# Категория 5 - Метаданные файлов
- EXIF в изображениях - GPS-координаты, модельустройства,дата съемки
- Методанные документов(PDF,Word,Excel) - автор, программа, использованая для создания, иногда - имя поьзователя Window-машины, где документы создавался

# Категория 6 - Утечки данных
- Have I Been Pwned и подобные - проверка, фигурирует ли email/домен в известных учтечках
- Pastebin  подобные "сливные" сайты - иногда там оказывается случайно опубликованые конфиги, пароли , внутренние документы

# Таблица надежности
| Источник | Надежность | Актуальность |
|----------|------------|--------------|
| Офицальный сайт компании | Высокая | Обычно актуально |
| WHOIS | Средняя(может быть скрыт privacy-guard) | Может быть устаревшим |
| LinkedIn | Средняя (люди не всегда обновляют) | Часто устаревшая |
| Wayback Machine | Высокая для истории, бесполезна для "сейчас" | Заведомо устаревшая (это и есть суть архива) |
| Shodan/Censys | Высокая для "что видно снаружи" | Зависит от частоты пересканирования сервиса |
| Форумы/Reddit | Низкая-средняя (нужна проверка) | Разная |
