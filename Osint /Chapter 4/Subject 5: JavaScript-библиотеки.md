# JavaScript-библиотеки
## Отдельно от фреймворков — конкретные подключаемые библиотеки: jQuery, Bootstrap, GSAP, Lodash и т.д

### Как определить:
- View Source → смотрbv теги <script src="...">, часто прямо в пути есть имя и версия: jquery-3.6.0.min.js
- В DevTools (F12) → вкладка Network → загруженные .js файлы
- Глобальные переменные в консоли браузера: набери jQuery.fn.jquery в консоли — вернёт версию, если jQuery используется
