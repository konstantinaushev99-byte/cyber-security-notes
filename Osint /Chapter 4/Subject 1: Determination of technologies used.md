# Determination of technologies used
## Суть - каждый сайт оставляет "отпечатки" — заголовки HTTP, специфичные пути к файлам, комментарии в коде, названия классов CSS, паттерны URL — которые выдают, на чём он построен

### Зачем это нужно в OSINT:
- Зная стек - можно искать публично известные уязвимости конкретной версии
- Понимание инфраструктуры компании
- Оценка зрлости security-практик компании (устаревший фреймворк = потенциально более уязвимая цель)

# Основные источники fingerprint'а
## HTTP-заголовки ответа сервера:
```bash
curl -I https://example.com
Смотрим на: Server:, X-Powered-By:, X-Generator: - иногда сервер сам честно себя называет
```

## HTML-код страницы:
- Meta-теги(<meta name="generator" content="WordPress 6.4">)
- Комментарии в коде
- Пути к статике(/wp-content/,/sites/defult/ - Drupal, /_next/ - Next.js)

## Специализированные инструменты-анализаторы 
- Wappalyzer, BuiltWith — браузерные расширения/сайты, которые автоматизируют весь этот процесс за нас, сразу выдавая список технологий
