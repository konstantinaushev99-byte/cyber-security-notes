# Web server
## Веб-сервер — это программа, которая физически принимает HTTP-запрос и отдаёт ответ (Nginx, Apache, IIS, LiteSpeed и т.д.). Определить его — самый простой и надёжный шаг fingerprinting'а

### Через HTTP-заголовок:
```bash
curl -I https://example.com
```
- Искать надо заголовок Server: в ответе - часто там написано nginx/1.24.0 или Apache/2.4.58
- Почему не всегда доверять этому заголовку:
  - Многие администраторы намеренно скрывают версию из соображение безопасности - чтобы не облегчить акатакующему поиск уязвимостей под конкретную версию
- Альтернативные признаки, если заголовок скрыт:
  - Формат страниц ошибок — у Nginx, Apache и IIS дефолтные страницы 404/403/500 выглядят по-разному, это иногда выдаёт сервер даже без заголовка
  - Порядок и набор HTTP-заголовков
  - Поведение с необычными запросами
