# PDF
## PDF-метаданные частично пересекаются с офисными документами, но есть нюансы:
- Author, Creator, Producer — три разных поля!
  - Creator - программа, которой создан исходный документ(напрмер Word)
  - Producer - прогрмма, которая сконвертировала его в PDF
 
- Если PDF был экспортирован из Word/Excel - метаданные исходного документа иногда "протекаю" в PDF-версию

### Инструменты
```bash
exiftool document.pdf
pdinfo document.pdf
```
