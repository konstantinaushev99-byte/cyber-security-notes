# Practice

# Вариант 1 ( с фотографией )
1. Возьмем оригинальное файл/фото
2. Прогонем через exiftool
  ```bash
  exiftool ИМЯ_ФАЙЛА
  ```
3. Что же мы нашли по фото (конкретно мой пример)
   - Координаты с точность до 3.5 метров (GPSPositioningError: 3.529364186)
   - Дату и время фото
   - Устройство,модель,софт,модель камеры
   - Направление съёмки(куда смотрела камера - GPSImgDirection: 304°)
   - Данные о лице на кадре (RegionType: Face)
   - Часовой пояс отдельно от времени (OffsetTime: +03:00)

# Какой можно сделать вывод:
Один HEIC-файл с iPhone содержит сотни полей метаданных, также там есть ICC-цветовые профили, HDR-данные, portrait-эффекты.
Большинство из них не про приватность (цветовые профили), но горстка критичных полей (GPS + время + модель устройства) в сумме дают почти исчерпывающий портрет: где, когда, на что снято

# Вариант 2 ( с документов)
1. Создам файл и сохраню как .docx
2. Также проганю через
   ```bash
   exiftool ИМЯ_ФАЙЛА
   ```
3. С exiftool не сработало , так как он не смог прочитать данные - 
Install Archive::Zip to decode compressed ZIP information
4. Сменил расширение файла с .docx на .zip и все получилось
5. Нашел такие значения как:
   - <dc:creator>Мое_Имя</dc:creator>
   - <cp:lastModifiedBy>Мое_Имя<cp:lastModifiedBy> - совпадает с creator, значит документ не пересылался/не редактировался другим человеком
   - <cp:revision>1</cp:revision> - почти не редоктировался
   - <dcterms:created>2026-09-04T08:43:00Z</dcterms:created>
     <dcterms:modified>2026-09-04T08:43:00Z</dcterms:modified>
