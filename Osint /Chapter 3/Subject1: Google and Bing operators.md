# Google/Bing operators
## Поисковые операторы - это специальные синтаксис, который сужает выдачу поискоика до конкретных, точных условий вместо обычного "ключевые слова + надейся". Работают почти одинаково в Google и Bing, с небольшими различиями в поддержке отдельных операторов

1. site: 
  Ограничивает поиск одним доменом (или поддоменом)
  ```bash
  site:example.com
  site:example.com "confidential"
  ```
  Показывает только то, что Google/Bing проиндексировали именно с этого домена. Полезно, чтобы быстро увидеть публичную 
  "поверхность" сайта — все проиндексированные страницы, поддомены, документы
2. filetype:
  Ищет файлы конкретного формата
  ```bash
  site:example.com filetype:pdf
  site:example.com filetype:xlsx
  ```
  Классика для поиска забытых публичных документов — презентаций, отчётов, таблиц с внутренними данными, которые кто-то
  случайно выложил в публичную папку сайта
3. intitle:
  Ищет слово именно в заголовке страницы (<title> теге), не в тексте
  ```bash
  intitle:"index of" site:example.com
  ```
  Последний пример — известный dork, находит открытые директории (незащищённые listing-страницы), где сервер просто 
  показывает 
  содержимое папки — часто там лежат файлы, которые не должны быть публично доступны
3. inurl:
  Ищет слово именно в URL, не в тексте страницы
  ```bash
  site:example.com inurl:admin
  site:example.com inurl:login
  ```
  Помогает найти админ-панели, страницы логина, тестовые/staging-URL, если они проиндексированы поисковиком (что само по 
  себе часто уже проблема безопасности для владельца сайта)
4. Комбинирование — сила метода именно в этом
  Операторы можно и нужно сочетать:
  ```bash
  site:example.com filetype:pdf intitle:confidential
  site:example.com inurl:wp-admin
  ```
